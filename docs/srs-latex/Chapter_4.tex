\section{Notes on the partial requirements}
\textbf{FR5.} Users do not sign transactions themselves yet. When a user registers, the server gives them one of the funded accounts on the local test chain and signs that user's transactions. This lets the whole flow run today. FR18 replaces it with MetaMask, after which the server will never hold a user's key.

\textbf{FR9.} A wallet created on the local test chain has no history, so there is nothing real to score. Until the system runs on a public test network, each freelancer is linked to one real wallet from the Kaggle dataset~\cite{kaggle}, and the engine scores that wallet. The demo accounts use a legitimate wallet and one the dataset labels as fraud. No synthetic data is used.
